# Drunix Remittance Solution

This project implements a secure and efficient cross-border remittance solution built on the Drunix blockchain, integrating a real payment gateway for seamless external transactions.

## Features

- **Blockchain Integration:** Leverages the Drunix blockchain for transparent and tamper-proof transaction records.
- **Real Payment Gateway:** Integrated with a functional gateway to handle external fund transfers.
- **Status Checking:** Includes functionality to verify the status of blockchain transactions via the Drunix node.

## Getting Started

These instructions will get you a copy of the project up and running on your local machine for development and testing purposes.

### Prerequisites

- Python 3.10+
- `requests` library

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/utsav08/Drunix-Remittance-Solution.git
   ```
2. Navigate to the project directory:
   ```bash
   cd Drunix-Remittance-Solution
   ```
3. Install required dependencies:
   ```bash
   pip install requests
   ```

### Usage

Run the main application:
```bash
python main.py
```
